# 本地启动指南

## 环境要求

- Node.js 18+，建议使用当前 Next.js 支持的 LTS 版本。
- npm 或 pnpm。
- SQLite 本地数据库。

## 安装依赖

```bash
npm install
```

如使用 pnpm：

```bash
pnpm install
```

## 配置环境变量

在项目根目录创建 `.env`：

```bash
DATABASE_URL="file:./dev.db"
AI_PROVIDER="mock"
QUALITY_GUARD_PROVIDER="mock"
OPENAI_API_KEY=""
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

本地 Demo 不需要真实模型 API。若后续接入真实 provider，API Key 必须通过环境变量配置，例如：

```bash
OPENAI_API_KEY="..."
```

## 初始化数据库

```bash
npm run prisma:generate
npm run prisma:migrate
npm run db:seed
```

## 启动开发服务器

```bash
npm run dev
```

默认访问：

```text
http://localhost:3000
```

如果 3000 端口被占用，可以使用：

```bash
npm run dev -- -p 3001
```

## 验证命令

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
