# LabelHub 比赛提交说明

## 提交项目

- 项目名称：LabelHub
- 项目定位：面向大模型训练数据生产的数据标注平台
- 当前交付分支：`submission-packaging`
- 技术栈：Next.js App Router、TypeScript、Tailwind CSS、shadcn/ui、Prisma、SQLite

## 本次提交包含

本目录用于比赛交付材料整理，所有内容基于当前仓库真实代码编写。

- 项目总览与核心链路说明
- 架构设计与 Mermaid 图
- 关键技术点说明
- AI Coding 过程记录
- 本地启动与 Demo 环境说明
- 核心 API 文档
- Demo 演示脚本
- 截图与 Demo 视频材料

## Demo 视频

- 视频链接：[LabelHub Demo Video](https://github.com/yuansiyuanxjtu/labelhub-ai-platform/releases/download/v1.0.0/LabelHub-demo-video.mp4)
- 托管方式：视频文件托管在 GitHub Release。
- 视频时长：约 5 分钟左右，以 Release 附件实际播放时长为准。
- 覆盖链路：任务负责人创建任务并配置动态表单，标注员提交标注，审核员查看 QualityGuard AI 预审并完成人工审核，最后导出数据。
- 本地复现：如果线上环境不可用，可以按照 `submission/05-本地启动指南.md` 本地启动项目，并结合 `submission/08-Demo演示脚本.md` 复现完整演示链路。

## 已实现能力边界

当前版本已经实现任务管理、动态表单配置、标注工作台、QualityGuard Agent mock 预审、人工审核、数据导出、Demo Mode、轻量 RBAC、审计日志、formSchema 版本管理和核心测试。

当前版本没有接入真实登录系统，没有接入真实 OpenAI 调用，没有实现批量文件上传、异步队列、生产部署和完整团队管理。这些内容在文档中作为后续扩展方向描述，不作为已完成能力申报。
